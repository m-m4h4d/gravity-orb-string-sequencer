# gravity-orb-string-sequencer
Gravity Orb &amp; String Sequencer is a single self-contained HTML file. It includes the Space FX toggle in the top HUD, which routes guitar plucks and percussion sends through a stereo ping-pong delay network and a 2.8-second procedurally generated stereo reverb, alongside real-time sheet music transcription, melody replay, and binary file export.

## Orbfall

The project goes by **Orbfall**. `landing.html` is the landing page: it covers every feature, follows the system light/dark theme (with a manual toggle), and links to the instrument at `index.html`. `favicon.svg` is shared by both pages.
